# 一键脚本安装 VapourSynth 的 MVTools 插帧功能

## Windows 用户安装教程
- 下载文件 [Install-VsMVTools.ps1](https://github.com/mpvConfig/mpvTools/raw/refs/heads/main/Install-VsMVTools.ps1)
- 放到 mpv播放器根目录下（`mpv.exe`同目录）
- 选中 `Install-VsMVTools.ps1`文件：右键 > 使用 powerShell 运行
- 运行成功会自动增加快捷键到 `input.conf` 右键菜单，无需任何操作设置
- 执行完后重启播放器，可通过右键菜单选择启用插帧
